# Changelog

## 0.1.0 — release candidate

- Integrate StatusNotifierItem entries into GNOME Shell 50 Background Apps.
- Merge matching native and tray entries, with native close fallback.
- Expose app-provided tray menus, clean Quit/Exit/Close, and Show/Open/Restore actions.
- Support nested DBusMenu items, menu icons, check/radio state, and keyboard navigation.
- Add configurable visibility, duplicate merging, and primary/middle-click behavior.
- Add validation, tests, and a packaged extension ZIP.
